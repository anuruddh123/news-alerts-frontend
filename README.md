# News Alerts Frontend

Frontend for the News Alerts application.

## Features

- User Authentication
- Real-time News Updates
- Push Notifications
- Responsive UI
- Category Filtering

## Tech Stack

- React
- Vite
- Tailwind CSS
- Axios
- Socket.io Client

## Setup

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file:

```env
VITE_API_URL=https://news-alerts-backend.onrender.com
VITE_GOOGLE_CLIENT_ID=your_google_client_id
```
